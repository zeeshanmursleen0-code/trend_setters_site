Trend Setters Privacy Policy

Last updated: October 24, 2026

This Privacy Policy describes the intended data handling practices for Trend Setters, a personal Pinterest affiliate-marketing automation project. Update this policy if the tool's actual behavior changes.

Information processed

The tool may process product information entered by its operator, including product names, affiliate URLs, image URLs, Pinterest board identifiers, and Pin descriptions. If Pinterest API integration is enabled, it may also process authorization tokens and information returned by Pinterest's API, such as board and Pin identifiers and publishing status.

Purpose of processing

Information is used to prepare product Pins, publish them when authorized, prevent duplicate processing, and diagnose errors. Affiliate links may be used as destination links so that the affiliate program can attribute eligible referrals.

Storage and security

Product data may be stored in local CSV files and logs on the operator's computer. API credentials should be stored securely, must not be shared publicly, and should never be committed to a public code repository. Do not store more information than is needed for the tool to work.

Sharing

The tool does not intentionally sell personal information. When API features are used, relevant requests and data are sent to Pinterest and may be processed under Pinterest's own terms and privacy policy. Affiliate destinations may also process visitors under the relevant merchant or affiliate program's policies.

Retention and deletion

The operator controls locally stored CSV files and logs and can delete them when no longer needed. Authorization can be revoked through the relevant account or application settings. Remove expired tokens from local storage and logs.

Children

This tool is not intended to collect personal information from children.

Changes

This policy should be updated whenever the tool's data collection, integrations, or storage practices change.

Contact

For privacy questions about this personal project, contact the project operator through the contact method associated with the website or app registration.
