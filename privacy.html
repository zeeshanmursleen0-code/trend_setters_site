Last updated: October 24, 2026

1. Introduction

This policy describes the information handled by the Trend Setters website and its associated personal Python product research tool. The tool currently runs locally on the operator's computer. This website does not currently offer user accounts or Pinterest publishing.

2. Information Collected Through This Website

This static website does not provide registration forms or intentionally collect personal information through website forms. The website operator has not intentionally added analytics, advertising pixels, or tracking cookies.

If you contact the operator by email, the operator receives your email address and the information you choose to include in your message. That information is used to respond to your inquiry.

The website is hosted through GitHub Pages. GitHub may process technical information, such as IP addresses and request logs, to operate and protect its services. Read GitHub's Privacy Statement for details.

3. Information Processed by the Local Python Tool

The local tool can request product information from the AliExpress affiliate API. Depending on the response, local CSV files may contain product titles, product URLs, image URLs, prices, commission-rate information, sales-volume indicators, evaluation data, product scores, and affiliate links.

This information is used by the operator for product research, comparison, ranking, and content preparation. The current tool is not intended to collect visitors' personal data.

API credentials and configuration values should be stored locally and must not be committed to this public repository. The operator is responsible for protecting credentials and complying with the relevant API provider's terms.

4. Pinterest Integration

Pinterest publishing is not currently connected or active. This project does not currently publish Pins or access Pinterest user accounts. If a Pinterest integration is added in the future, this policy will need to be reviewed and updated to describe the actual data accessed and processed.

5. Third-Party Services

6. Data Retention and Security

No system can be guaranteed completely secure. Do not send passwords, API secrets, payment information, or other sensitive information to the project by email.
